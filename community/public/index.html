A few tips from the forest floor
  • Look at the original image before viewing AI suggestions. Small changes in color or texture can matter.
  • Draw a tight box around each visible mushroom, even if you don’t know its group. Use separate boxes where you can distinguish individuals.
  • Only label what this frame shows. A mushroom in a later frame does not automatically make it visible here.
  • “Not sure” is valuable for blur, shadows, and tiny shapes. It records uncertainty without claiming that a particular patch is a mushroom.
  • Use the coordinate fields to adjust a box without dragging. Arrow keys move a selected box; hold Shift for ten pixels.
